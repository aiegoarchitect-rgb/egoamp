# Hola A1

Мобильное приложение для изучения испанского с нуля до уровня A1, в духе Duolingo, но проще.
Работает в браузере телефона, ставится на главный экран как обычное приложение и после первого открытия работает без интернета.

## Что внутри

**12 тем** (около 150 слов и 72 фразы): приветствия, числа, семья и глагол *ser*, цвета и прилагательные,
еда, город и глагол *estar*, дни и время, глаголы на -ar/-er/-ir, распорядок дня, хобби и *gustar*,
покупки, поездки и планы (*ir a*, *tener que*).

В каждой теме 4 урока: «Слова 1», «Слова 2», «Фразы» и «Итог». К каждой теме есть короткая памятка по грамматике.

**Типы упражнений:**
- выбор перевода (испанский → русский и обратно);
- аудирование: прослушать и выбрать, что прозвучало (есть медленная озвучка);
- сопоставление пар;
- сборка фразы из слов;
- ввод ответа с клавиатуры, с кнопками á é í ó ú ñ ¿ ¡.

**Мотивация и память:**
- опыт (XP), цель дня 30 XP, серия дней подряд;
- неправильные ответы повторяются в конце урока;
- интервальное повторение: слова возвращаются через 1, 2, 4, 8, 16 и 32 дня;
- словарь с поиском и озвучкой всех открытых слов.

Озвучка использует встроенный синтезатор речи телефона (Web Speech API), поэтому файлов со звуком нет.
Если испанский голос не установлен, его можно добавить в настройках: iOS → Универсальный доступ → Устный контент → Голоса;
Android → Настройки → Синтез речи → Google → Установить голосовые данные → Español.

Прогресс хранится только на устройстве (localStorage).

## Как запустить

Сборка не нужна, это обычные статические файлы.

```bash
npx serve .        # или python3 -m http.server
```

Чтобы поставить приложение на телефон, его нужно выложить на любой HTTPS-хостинг. Проще всего через GitHub Pages:
Settings → Pages → Deploy from a branch → выбрать ветку и папку `/ (root)`.
Затем откройте ссылку на телефоне и нажмите «На экран Домой» (Safari) или «Установить приложение» (Chrome).

## Файлы

| Файл | Что это |
|---|---|
| `data.js` | весь курс: слова, фразы, памятки. Чтобы добавить тему, допишите объект в `units` |
| `app.js` | логика приложения: уроки, упражнения, повторение, прогресс |
| `app.css` | оформление, светлая и тёмная тема |
| `sw.js`, `manifest.webmanifest` | установка на телефон и работа без интернета |
